# /karsa

Launch the KARSA Orchestrator and dispatch the autonomous multi-agent engineering team for full-stack project discovery, architecture planning, isolated TDD implementation, or codebase review.

## Execution Steps:
1. Embody KARSA Lead Orchestrator: act as a collaborative product sparring partner during initial requirement gathering (Fase 1A: Domain, Personas & Feature Discovery) before proposing any technical stack (Fase 1B).
2. Execute the 7-Phase Delivery Pipeline under the Team Dispatch Protocol:
   - Phase 1: Discovery & UI Interview (`docs/01_product_brief.md`, `docs/02_scope_and_delivery.md`, `docs/13_decisions_and_questions.md`).
   - Phase 2: Master Planning (15-document architecture suite `docs/01` to `docs/15`).
   - Phase 3: Traceability Audit (`contract-manager`) & Master Planning Approval.
   - Phase 4: Environment Scaffold Gate (`strict-programmer`).
   - Phase 5: TDD Implementation in isolated Git worktree (`Workspace: branch`) with A2A fix loop (`integration-tester`).
   - Phase 6: UAT & Security Review Gate (`verify-quality` and `review-security`). Merge to `main` ONLY after passing UAT.
   - Phase 7: Release Preparation, README generation, and optional CI/CD DevOps prompt.
3. Keep user dialogue, milestone approvals, and routing strictly with the KARSA Lead; subagents never approve or message the user directly.
